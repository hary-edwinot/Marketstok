| Dossier         | Rôle                                                                                |
| --------------- | ----------------------------------------------------------------------------------- |
| **api/**        | Centralise les requêtes HTTP vers ton backend Node.js (Axios configuré).            |
| **components/** | Contient les composants génériques réutilisables (boutons, cartes, navbar...).      |
| **features/**   | Chaque “feature” (auth, dashboard, user) a son propre slice, actions et composants. |
| **hooks/**      | Pour extraire la logique réutilisable (authentification, requêtes...).              |
| **pages/**      | Contient les pages principales du site (Home, Login).                 |
| **redux/**      | Contient la configuration du store Redux Toolkit.                                   |
| **styled/**     | Fichiers Tailwind + styles globaux.                                                 |
| **utils/**      | Fonctions de formatage ou constantes globales.                                      |
